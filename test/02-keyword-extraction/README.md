# KOSIS 검색 키워드 생성

상위 단계에서 전달받은 통계 지표명 `metric`을 원키워드로 보존하고, 검색에 활용할 관련 키워드 후보 목록을 만드는 모듈입니다.

## 입력

키워드 생성의 기준은 `metric`입니다. `claim_id`는 결과를 원본 Claim과 연결하기 위해 그대로 보존합니다.

```json
{
  "claim_id": "C001",
  "metric": "항공사 정비사 수",
  "kosis_eligible": true
}
```

## 출력

```json
{
  "claim_id": "C001",
  "metric": "항공사 정비사 수",
  "original_keyword": "항공사 정비사 수",
  "keywords": [
    "항공사 정비사 수",
    "항공사 정비사",
    "정비사 수"
  ],
  "status": "success",
  "error_message": ""
}
```

## 처리 파이프라인

```text
입력 객체
  → metric 추출·공백 정규화
  → 원키워드 보존
  → 규칙 기반 후보 생성
  → 후보 목록 병합
  → 공백·빈 값·중복 정리
  → keywords 반환
```

`kosis_eligible`가 정확히 `true`일 때만 키워드 목록을 생성합니다. 그렇지 않으면 `keywords`는 빈 목록으로 반환합니다.

## 키워드 생성 방식

- 원본 `metric`은 항상 첫 번째 키워드 후보로 유지합니다.
- `수`, `인원`, `인구`, `비율`, `비중`, `규모`, `현황`처럼 일반적인 측정 표현이 마지막에 있으면, 이를 뺀 표현도 후보로 만듭니다.
- 두 단어 이상인 metric은 앞 또는 뒤 토큰을 제외한 표현도 후보로 추가합니다.
- 후보는 생성 순서를 유지하며, 공백 차이·빈 값·중복을 정리합니다.

예를 들어 `항공사 정비사 수`는 원표현을 유지하면서 `항공사 정비사`, `정비사 수`를 함께 후보로 만듭니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `src/keyword_generator.py` | metric을 원키워드로 보존하고 관련 키워드 후보를 생성·병합·정리해 반환하는 기본 처리 로직 |
| `tests/test_keyword_generator.py` | 입력 검증·후보 생성·병합·중복 제거 테스트 |
