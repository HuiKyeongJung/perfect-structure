## 4. `sample_keywords.json` 파일 위치 오류

다음으로 아래 오류가 발생했다.

```text
FileNotFoundError:
No such file or directory:
backup\kosis_keyword_search\src\sample_keywords.json
```

### 원인

`main()` 함수에서 `sample_keywords.json`을 `keyword_search.py`와 같은 폴더인 `src` 안에서 찾고 있었다.

```python
base_dir = Path(__file__).resolve().parent
input_path = base_dir / "sample_keywords.json"
```

이 구조에서는 `sample_keywords.json`이 아래 위치에 있어야 한다.

```text
backup/kosis_keyword_search/src/sample_keywords.json
```

### 해결

`sample_keywords.json` 파일을 `src` 폴더 안으로 이동했다.

현재는 아래 구조가 되었기 때문에 `main()`의 `base_dir`은 그대로 유지하면 된다.

```text
backup/
  kosis_keyword_search/
    src/
      keyword_search.py
      sample_keywords.json
```

## 5. `.env` 파일 위치 오류

그다음 아래 오류가 발생했다.

```text
FileNotFoundError:
.env 파일을 찾을 수 없습니다:
backup\kosis_keyword_search\src\.env
```

### 원인

`load_api_key()` 함수가 `.env`를 `src` 폴더 안에서 찾고 있었다.

```python
env_path = Path(__file__).resolve().parent / ".env"
```

하지만 실제 `.env` 파일은 `src` 안이 아니라 `kosis_keyword_search` 폴더 바로 아래에 있었다.

```text
backup/kosis_keyword_search/.env
```

### 해결

`.env`는 코드 파일보다 한 단계 위 폴더에 있으므로, `parent.parent`를 사용하도록 수정해야 한다.

```python
env_path = Path(__file__).resolve().parent.parent / ".env"
```

의미는 다음과 같다.

```text
Path(__file__).resolve().parent        → src 폴더
Path(__file__).resolve().parent.parent → kosis_keyword_search 폴더
```

## 6. KOSIS API 응답 파싱 오류

파일 경로 문제를 해결한 뒤, KOSIS API 요청은 실제로 성공했다.

하지만 결과는 아래처럼 나왔다.

```json
{
  "keyword": "소비자물가지수",
  "exists": false,
  "status": "error",
  "error_reason": "KOSIS API 응답이 JSON 형식이 아닙니다..."
}
```

첨부된 `raw_text`를 확인해보니 KOSIS 응답은 아래와 같은 형태였다.

```text
[{ORG_ID:"101",ORG_NM:"국가데이터처",TBL_ID:"DT_1J22042",TBL_NM:"월별 소비자물가 등락률",...}]
```

### 확인한 사실

KOSIS에서 검색 결과 자체는 정상적으로 오고 있었다.

예를 들어 응답 안에 아래 정보들이 포함되어 있었다.

```text
ORG_ID
TBL_ID
TBL_NM
STAT_NM
LINK_URL
```

즉, 문제는 "검색 결과가 없음"이 아니라 "받은 응답을 Python이 JSON으로 해석하지 못함"이었다.

## 7. 왜 JSON으로 인식하지 못했는가

Python의 `json.loads()`는 표준 JSON 형식만 읽을 수 있다.

표준 JSON은 key에도 반드시 따옴표가 있어야 한다.

정상 JSON 예시:

```json
[
  {
    "ORG_ID": "101",
    "TBL_ID": "DT_1J22042"
  }
]
```

하지만 실제 KOSIS 응답은 key에 따옴표가 빠져 있었다.

KOSIS 응답 예시:

```text
[
  {
    ORG_ID: "101",
    TBL_ID: "DT_1J22042"
  }
]
```

겉으로는 리스트처럼 보이지만, Python 기준으로는 표준 JSON이 아니다.

따라서 아래 코드에서 실패했다.

```python
json.loads(raw_text)
```

## 8. string 객체와 list 객체 관련 정리

오늘 헷갈렸던 부분은 "list 객체가 아니라 string 객체로 받아서 실패한 것인가?"였다.

정확한 설명은 다음과 같다.

```text
raw_text가 string인 것은 정상이다.
API 응답은 처음에는 항상 문자열로 들어온다.
문제는 그 문자열 안의 내용이 표준 JSON 문법이 아니었다는 점이다.
그래서 json.loads()가 문자열을 list/dict 객체로 변환하지 못했다.
```

즉, 이번 문제는 아래처럼 정리할 수 있다.

```text
KOSIS 응답은 문자열로 정상 수신됐다.
하지만 표준 JSON 형식이 아니라 Python list/dict로 파싱되지 않았다.
```

## 9. 수정 방향

### 9-1. `re` import 추가

KOSIS식 응답에서 따옴표 없는 key를 고치기 위해 정규표현식을 사용한다.

```python
import re
```

### 9-2. `fetch_json()` 함수 수정

KOSIS 응답이 표준 JSON이면 그대로 읽고, 실패하면 key에 따옴표를 붙인 뒤 다시 읽는다.

```python
def fetch_json(url: str) -> Any:
    """KOSIS API 응답을 읽고, KOSIS식 응답을 Python dict/list로 변환한다."""
    request = Request(
        url,
        headers={
            "User-Agent": "Mozilla/5.0",
            "Accept": "application/json",
        },
    )

    with urlopen(request, timeout=15) as response:
        raw_text = response.read().decode("utf-8")

    if not raw_text.strip():
        raise ValueError("KOSIS API 응답이 비어 있습니다.")

    try:
        return json.loads(raw_text)
    except json.JSONDecodeError:
        fixed_text = re.sub(
            r'([{,]\s*)([A-Za-z_][A-Za-z0-9_]*)(\s*:)',
            r'\1"\2"\3',
            raw_text,
        )
        return json.loads(fixed_text)
```

### 9-3. 검색 결과 없음 처리

없는 키워드는 아래처럼 올 수 있다.

```text
{err:"30",errMsg:"데이터가 존재하지 않습니다."}
```

이 경우는 프로그램 오류라기보다 검색 결과가 없는 상태로 보는 것이 적절하다.

따라서 `normalize_response_items()`에서 `err == "30"`이면 빈 리스트를 반환하도록 한다.

```python
def normalize_response_items(data: Any) -> list[dict[str, Any]]:
    if isinstance(data, dict):
        if data.get("err") == "30":
            return []

        for key in ("result", "data", "list", "rows"):
            value = data.get(key)
            if isinstance(value, list):
                return [item for item in value if isinstance(item, dict)]

    if isinstance(data, list):
        return [item for item in data if isinstance(item, dict)]

    return []
```

## 11. 오늘 기준 정리

오늘 확인한 핵심은 다음과 같다.

| 문제 | 원인 | 해결 방향 |
|---|---|---|
| `keyword_search.py` 파일을 못 찾음 | 실제 파일이 `src` 안에 있었음 | 실행 경로를 `src/keyword_search.py`로 수정 |

| 없는 키워드도 error 처리됨 | `{err:"30"}` 응답 처리 규칙 없음 | `err == "30"`이면 결과 없음으로 처리 |
